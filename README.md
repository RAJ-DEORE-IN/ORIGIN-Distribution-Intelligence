# ORIGIN — Distribution Intelligence & Inventory Optimization Engine

**Team ORIGIN | Problem Statement 2**

## About the Project

ORIGIN is a web-based decision-support system designed to help FMCG businesses improve inventory allocation and distribution across warehouses and retail locations.

It aims to identify stock shortages, available surplus inventory, demand patterns, transportation costs, and expiry risks to generate explainable transfer recommendations.

## Key Capabilities

- Inventory and demand analysis
- CSV data processing
- Inventory risk analysis
- Distribution recommendations
- Scenario comparison
- AI assistant integration
- Research-backed optimization approach

## Technology Stack

- React
- TypeScript
- Vite
- Node.js
- Firebase
- Google Gemini API

## Getting Started

### Prerequisites
- Node.js
- npm

### Installation

1. Clone this repository.
2. Install dependencies:

   `npm install`

3. Configure the required environment variables using `.env.example` as a reference. Create a local `.env.local` file and add your own API credentials.

4. Start the development server:

   `npm run dev`
